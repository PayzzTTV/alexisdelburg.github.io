06 / 06

RootGuard

Outil CLI Python de surveillance de l'intégrité des fichiers critiques d'un système Linux. Génère une baseline cryptographique SHA-256 des chemins système (/bin, /sbin, /etc, /usr/bin, /boot, /lib), stockée en lecture seule (chmod 400), puis compare à chaque scan pour détecter toute modification (CRITICAL), ajout (HIGH) ou suppression (MEDIUM) — typiques d'une infection rootkit ou d'une compromission post-exploitation.

Pipeline CI/CD complet : lint → test → SAST Bandit → docker-build → Trivy scan (CI), puis build-and-push GHCR → release (CD). Image Docker non-root multi-stage, export JSON compatible SIEM (Splunk, Elasticsearch). Conçu pour s'intégrer en CronJob Kubernetes ou pipeline DevSecOps Shift Left.
